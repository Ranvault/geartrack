# geartrack
Tugas Sistem Manajemen Sederhana - Sistem Rental Alat Outdoor
## Konfigurasi Database

1. Jalankan Laragon dan aktifkan layanan MySQL/MariaDB.
2. Buat database bernama `geartrack`.
3. Impor file `geartrack.sql` yang disediakan.
4. Sesuaikan host, nama database, username, dan password dengan konfigurasi lokal.
5. Jalankan aplikasi melalui browser.
